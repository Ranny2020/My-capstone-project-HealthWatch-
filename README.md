# My-capstone-project-HealthWatch-
HealthWatch is a user-friendly public health web application designed to help users monitor their health, access essential health information, and stay informed about preventive healthcare. the project focus on creating a simple, accessible and responsive interface using modern UI development principles.
Project Objective:
The goal of Healthwatch is to provide users wit a simple digital platform where they can:
1. Monitor important health information
2. Access health and wellness resources
3. easily navigate essential health information
Features:
1. User Authentication: login and registration interfaces for users
2. Health Dashboard
3. User profile
4. Responsive design
5. Health Tracking
Technologies Used:
1. HTML5
2. CSS3
3. JavaScript
4. Figma
5. Git & github
6. netilify
